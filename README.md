# 📊 Blinkit Sales Dashboard | Power BI

An interactive Power BI dashboard designed to analyze Blinkit's sales performance, outlet characteristics, item-level performance, customer ratings, and outlet distribution.

## 📌 Dashboard Preview

![Blinkit Dashboard](BLINKIT%20DASHBOARD.png)

## 🎯 Project Objective

The objective of this project is to analyze Blinkit's sales data and identify key patterns and performance trends across:

- Outlet types and locations
- Item categories and sales contribution
- Outlet sizes
- Fat content
- Customer ratings
- Outlet establishment trends

## 📊 Key Performance Indicators

| KPI | Value |
|---|---:|
| Total Sales | $1.20M |
| Average Sales | $141 |
| Number of Items | 8,523 |
| Average Rating | 3.9 |

## 📈 Dashboard Features

### Sales Performance
- Total Sales and Average Sales analysis
- Outlet establishment trend over the years
- Sales comparison across outlet types

### Product Analysis
- Item type-wise sales contribution
- Fat content analysis
- Product performance comparison

### Outlet Analysis
- Outlet size distribution
- Outlet location analysis
- Tier-wise outlet performance
- Outlet type comparison

### Interactive Filters
- Outlet Location Type
- Outlet Size
- Item Type

## 💡 Key Insights

- Supermarket outlets contribute significantly to overall sales.
- Tier-based analysis helps identify differences in outlet performance.
- Item type and fat content provide insights into product-level sales.
- Outlet establishment trends help understand sales performance over time.
- Interactive filters allow users to explore the data from different perspectives.
